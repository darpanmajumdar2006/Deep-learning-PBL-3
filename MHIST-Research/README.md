# MHIST Research

Workspace for MHIST image classification experiments.

## Structure

- `data/`: raw, processed, and metadata files
- `notebooks/`: exploration and experiment notebooks
- `src/`: reusable dataset, training, evaluation, robustness, Grad-CAM, and metric code
- `models/`: checkpoints and model configurations
- `results/`: figures, tables, and predictions

Install the initial dependencies with:

```bash
pip install -r requirements.txt
```
